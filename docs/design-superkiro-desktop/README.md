# Superkiro 桌面端 Metal 设计

范围：仅 Pencil 桌面设计与静态预览。云端管理后台、用户门户、客户端代码及生产环境均未修改。

## 页面

E01–E06：登录、已连接、待连接、用量、连接诊断、设置。
E07–E13：未找到 Kiro、连接中、卡密到期、恢复失败、登录失败、用量空状态、脱敏报告预览。
E14：启用、恢复、退出、切换卡密、连接超时、余额不足、网络失败、报告导出反馈。

## 交互约束

- 登录只验证卡密和获取权益，验证成功进入待连接页；手动点击启用才修改本机环境。
- 未识别安装位置时支持重新检测与选择 Kiro.exe；写入前校验路径与版本。
- 连接过程中展示真实步骤，不能把写入成功等同于模型服务可用。超时转入诊断，不无限显示处理中。
- 诊断保留四项导航，报告提供明确返回入口。不展示网关 IP 或上游密钥。
- 恢复只处理本软件修改的配置和证书，失败保留备份及诊断入口。
- 退出、切换卡密前先确认恢复。关闭窗口收至托盘，不等于退出进程。
- 用量只显示已结算消耗。空状态、加载失败、余额不足不同；参考价格未配置时不捏造美元估算。
- 内存优化自动执行，图表接真实进程采样；不强制终止正在编辑的进程。
- 示例数据不代表当前套餐、余额、版本、路径或真实费用。报告导出前须进行真实脱敏。

## 动效与可访问性（实施要求，未实现）

- 光栅仅在验证和连接转换时短暂响应；空闲静止。请求活动不可用装饰性随机数冒充。
- 主操作反馈 120–180ms，状态切换 220–320ms。减少动态效果模式禁用光栅动画。
- 按钮需补齐 hover、focus、pressed、disabled 状态，重复提交期间禁用操作。
- 弹窗限制焦点并支持安全取消；破坏性操作不默认聚焦确认按钮。修改配置的中间步骤不可直接中断。
- 桌面页面以 620×820 为主，登录 480×620；落地需适配系统缩放、键盘导航与屏幕阅读器。
## 独立审阅后的修订

- 用还原 Kiro 配置表述移除当前接入，避免与重连混淆。
- 退出弹窗增加取消；Esc 应返回当前窗口且不改变连接。
- 连接中展示已等待时间及阈值，12 秒/60 秒仅为状态示例，实施应使用实际步骤超时。关闭窗口收至托盘继续，不能直接退出中断。
- 内存数值明确为当前占用，自动维护已开启不等于正在维护。
- Pencil 布局检查未发现裁切问题；未进行客户端代码或端到端功能验收。
