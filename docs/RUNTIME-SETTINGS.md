# 在线运行参数

管理员后台「运行参数」及 `GET/POST /api/v1/admin/runtime-settings` 共用账本快照中的持久配置，不需要重新编译或重启。POST 使用管理员鉴权与 CSRF，提交 `expected_revision`、非空 `reason`、完整 `settings`。旧 revision 拒绝覆盖；保存失败不改变活动参数。所有变更保留最近 128 条审计。新请求固定一份配置供重试与后备路由使用，进行中的请求不受修改影响。

`settings` 包含 `standard`、`reasoning`、`claude` 三个超时档，每档：

| 字段 | 秒范围 | 含义 |
|---|---|---|
| headers_secs | 1–300 | 上游响应头等待 |
| attempt_secs | 1–900 | 单次模型启动等待 |
| total_secs | 1–1800 | 全部重试的模型启动预算 |
| commit_secs | 1–45 | 最迟开始返回响应头、保活 |
| started_secs | 60–3600 | 单次上游请求、看门狗和流发送时长上限 |
| idle_secs | 10–3600 | 上游流空闲等待 |

另有 `keepalive_secs`（1–25）与 `openai_reasoning_idle_secs`（10–3600，只针对 OpenAI 协议上的思考模型，并按目标模型请求上限截断）。响应头 ≤ 单次启动 ≤ 启动总预算 ≤ 请求上限；空闲 ≤ 请求上限；保活间隔 < 空闲。积分预扣存活期覆盖启动预算、最多三次尝试与结算余量，防止长请求过早释放预扣。

默认值与此前正常生产逻辑一致，不因开放设置而自动扩大超时。供应商地址、密钥、模型路由、价格、权益和响应模板已有独立管理页面/API，无需重新编译。TLS、监听端口、主加密密钥、存储路径和基础设施限额属于启动/部署安全配置，不开放网页热改。

## 响应模板

每模型变体新增 `delay_ms`（0–30000，旧记录默认 0）。只在工具参数校验与响应编码成功后等待，等待期间占用卡级并发名额，与普通请求共用上限，并提前校验卡状态及可用积分；等待取消释放名额且不会产生扣费；到期重新执行原有原子鉴权/配置版本校验与扣费。重放原回执不再等待或收费。延迟是模板服务等待，不生成虚假的思考或上游用量。

鹈鹕示例使用提供的完整 HTML，精确模型 ID `claude-opus-5-5`，文件名 `pelican-bicycle-opus5.5.html`，等待 1500ms。完整指定提示采用包含匹配，开头/末尾空白被忽略；不同模型不共享该变体。示例按钮仍创建禁用、免费草稿，需要明确发布启用。生产模板通过管理 API 单独发布，不硬编码进网关启动数据。
