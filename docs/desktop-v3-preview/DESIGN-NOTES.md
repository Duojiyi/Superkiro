## 核心流程
卡密验证 → 权益同步 → 概览（未连接）→ 自动检测安装目录 / 手动选择 → 用户确认 → 备份、证书、配置、重启、验证 → 已连接或诊断。
登录不能安装证书、修改 Kiro 或自动启用连接。
成功必须表示模型列表与服务校验通过，不能把配置写入成功等同于请求可用。
恢复只移除本应用拥有的证书和配置，不删除其他应用或用户证书。恢复失败保留应用并给出诊断。
关闭窗口默认进入托盘；真正退出提供恢复并退出、留在托盘、取消。进程必须运行才能工作的连接不得显示“退出后仍可用”。

## 数据与隐私
全部数字、日期、模型名、路径为示例，不代表真实业务状态。美元值为参考价格估算，不是采购成本、实际付费或积分兑换率。
参考价按模型区分输入、输出及缓存类别；缺少任一适用价格时标注部分估算，不将未知视为零。
网关地址及上游凭据不在普通界面展示；报告先脱敏预览再导出。隐藏界面字段不代替客户端安全防护。
记住卡密应使用操作系统凭据保护，不明文保存；未实现前不得宣称已保护。

## 交互与实现验收标准
- 默认1040×740，最小建议960×700；125%/150% DPI时允许内容区滚动，导航与主操作不消失。不能通过缩小字体适配。
- 所有交互提供默认、悬停、按下、键盘焦点、禁用、加载、错误状态；焦点环2px且可见；图标按钮有可访问名称。
- Enter提交登录，验证中防重复提交；失败保留卡密；网络错误不等同卡密无效。
- 路径选择后显示完整路径和版本并校验Kiro.exe，校验失败就地提示，成功仍需手动启用。
- 连接中逐步反馈；超时进入可操作诊断；修复成功同步概览状态。
- 图表提供积分/Tokens/美元切换、单位与文本明细；Tokens区分输入输出。缓存计价遵循实际后端数据。
- 内存自动监测默认启用；仅在空闲且策略支持时安全维护；忙碌时等待。展示峰值和维护时间，不伪造释放量。
- 150–200ms状态过渡，遵循减少动态效果；无滚动劫持、营销入场或持续装饰动画。
- 需在实现时验证对比度、键盘操作、屏幕阅读器、DPI和真实数据；本轮Pencil截图检查不替代运行验收。
