# Superkiro Web V5 · Signal Metal

## 范围
本轮是 Pencil 设计提案，不是生产部署或功能验收。保留既有桌面和后台设计；新增官网、换机和文档。源文件：../portal-pencil-v2/portal-v2.pen。

## Design Read
让准备使用 Superkiro 的用户先理解产品并下载正确版本，让已有用户快速换机和查阅操作说明。

## 旧结构的三个问题
1. 把普通用户带进配置后台：隐藏网关、上游、供应商成本等内部信息，公共站只保留下载、帮助、换机。
2. 首页既像营销页又像账户控制台：首页介绍产品，实际账户与用量留在客户端。
3. 视觉与操作层级混杂：首页允许材质与波形展示，换机和文档强调操作与阅读。

## 研究来源与限制
- https://www.awwwards.com/websites/software/：实际浏览软件作品分类与截图。该页面包含提名作品，不能把所有作品称为获奖作品。借鉴产品舞台与大标题，不照搬泛滥的高饱和渐变。
- https://linear.app/：实际访问、读取页面和截图。借鉴以产品界面作证据、克制导航。截图遇到入场过渡，不把它当作完整动效测量。
- https://www.raycast.com/：实际访问、读取页面和截图。借鉴平台下载主操作与就近系统要求。
- https://motionsites.com：连接失败 ERR_CONNECTION_CLOSED，未声称完成该站调研。
- 本地 D:/Desktop/atelier：采用 brand/product 分层、CJK 排版、token 优先和独立评审。

## 信息架构
- /：产品首屏、三步上手、平台下载、支持链接。
- /device：卡密验证、脱敏绑定信息、解绑确认、结果与恢复路径。
- /docs：快速开始、模型与积分、换机、恢复、连接故障、版本下载。
- /admin：独立管理员鉴权入口，既有后台保留。入口可见不代表允许未授权访问。

下载不额外制造中转页。首页支持按平台推荐，始终允许手动选择。公共下载不能指向私有源码仓库的受限 artifact；正式落地需独立发布存储、签名元数据和校验值。Mac 尚未签名与公证，也未完成真实 IDE 全流程验收，必须保持测试版状态提示。

## 视觉与动效
首页：视觉变化 8 / 动效 6 / 密度 4；工具页：4 / 2 / 5。
色彩为石墨底、冷银文字、灰绿色中性边界；品牌重点是沿用 Metal 材质的多模型汇入图形，不使用大面积蓝色或金色。
字体：Archivo（品牌与数字），Noto Sans SC（中文）。正文 16–17px，手机阅读正文 17px。颜色落地前仍需正式 token/对比度测试，不声称本轮已做完整无障碍验收。

首屏签名元素：三条模型信号轨迹汇入同一个 Kiro 工作区。静态稿只展示关键帧，不代表动效已经实现。
- 指针在产品展示区移动：最多 4px 位移，240ms 阻尼；按钮位置不随之漂移。
- 信号活动：沿轨道移动的低亮度脉冲，非全屏闪烁；进入视区后才运行，离开视区/标签页隐藏即暂停。
- 平台选择与状态切换：180–240ms 淡入，不延迟实际下载。
- prefers-reduced-motion：关闭循环与视差，只保留瞬时状态更新。
- 禁止滚动劫持、等待开场动画、把模型调用状态伪装成真实在线数据。

## 换机实现边界
卡密仅经 HTTPS 请求体提交；不放 URL、分析事件或日志，展示设备信息前先验证。服务端负责限速、解绑权限与冷却规则，不靠前端隐藏按钮。解绑应原子撤销旧设备凭证并保留额度与有效期；新客户端下一次验证完成绑定。不宣称网页能够恢复旧电脑文件。
所有设计示例设备、等级和积分都为演示数据。

## 验证边界
检查 Pencil 渲染与截图，不涉及服务器或真实账户操作。PNG 为静态设计预览；未运行网页 DOM、键盘访问、下载链路或响应式浏览器测试。上线前需要实现后单独验收。


## 独立评审与本轮修订
评审者收到任务约束与导出图片，未收到主设计者的自评分或赞许性解释。这是独立评审，不声称严格双盲实验。
- 下载入口：统一为“选择 Mac 版本”，新增芯片选择状态，签名状态移至首屏入口附近。
- 换机：前置旧客户端恢复提醒，按钮明确为“解绑已绑定设备”，补充手机验证后与确认状态。
- 文档：新增明确平台选中态，手机保留可能重启 IDE 的提醒。
- 视觉：音频波形替换为多模型汇入图形，标注概念示意；手机提前呈现该图形。
- 节奏：缩短官网步骤区与下载区空高度，减少手机全局间距。

待实现验证：真实版本元数据、平台下载链接、卡密输入状态与错误映射、解绑接口、键盘焦点与读屏语义、最终色彩对比度、实际响应式和动效性能。设计稿不应替代这些验证。
