# P4-7 审计报告: 分组级系统提示词注入 (Group-level System Prompt Prefix Injection)

## 1. 任务概述
- **任务目标**: 支持租户分组级系统提示词前缀注入 (`system_prompt_prefix`)：
  1. 保证企业租户自定义安全边界、编码规范与合规提示词强制前置注入
  2. 支持动态占位符插值渲染：`{{card_id}}` / `{{user_id}}` / `{{group_id}}` / `{{group_name}}` / `{{plan_name}}`
  3. 支持主流上游协议：
     - OpenAI 兼容协议（注入至 messages 数组第一条 system 消息头部，或新增 system 消息）
     - Anthropic 兼容协议（提取并注入至顶层 `system` 字段参数）
- **极简原则 (Ponytail)**:
  - 核心模板插值采用标准库字符串替换，无需引入重量级模板引擎 (Jinja/Tera/Handlebars)
  - 与已有的 `Group` 模型与 `BillingEngine` 紧密集成
  - 零性能损耗，注入逻辑仅在请求准备阶段执行一次

## 2. 变更范围
- `crates/gateway/src/facade/conversation.rs`:
  - 实现 `render_system_prompt_template`，完成占位符动态展开
  - 对话流处理步骤 8b 注入渲染后的系统提示词
- `crates/gateway/tests/system_prompt_injection_test.rs`:
  - 模板占位符渲染单元测试
  - OpenAI 提供商全链路注入集成测试
  - Anthropic 提供商顶层 `system` 字段全链路注入集成测试

## 3. 测试验证
- `cargo test --test system_prompt_injection_test`: 全部通过 (3/3 passed)
- 覆盖率验证：
  - `test_render_system_prompt_template_placeholders`: 验证卡号、分组名、套餐名占位符插值
  - `test_system_prompt_injection_openai_flow`: 模拟 OpenAI 上游验证 system 提示词正确前置
  - `test_system_prompt_injection_anthropic_flow`: 模拟 Anthropic 上游验证 `system` 字段正确注入

## 4. 结论
- P4-7 审计通过，分组级系统提示词注入机制完整且通过双盲测试。
