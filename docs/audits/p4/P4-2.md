# P4-2 视觉降级 Vision Fallback (P4-2.md)

## 完成声明（实现者）
- 文件：
  - `crates/gateway/src/translate/vision.rs`：新增视觉降级核心逻辑，支持模型能力自动判定（`model_supports_vision`）、结构化降级文本转换模板（`format_fallback_description`）、内存哈希缓存（`VisionFallbackCache`）与上游独立视觉模型转文字接口（`transcribe_image_with_provider`）。
  - `crates/gateway/src/translate/to_provider.rs`：在 `TranslationContext` 中引入 `supports_vision` 与 `image_transcriptions` 字段，当目标模型不支持看图时自动触发视觉降级，将图像二进制替换为结构化转录文本，杜绝上游 400 报错。
  - `crates/gateway/src/translate/mod.rs`：导出 `vision` 模块核心能力。
  - `crates/gateway/src/facade/models.rs`：为 `ModelInfo` 增加 `supports_vision` 字段（serde 默认 true）。
  - `crates/gateway/src/facade/virtualization.rs`：为默认模型（DeepSeek 纯文本 vs Claude 多模态）准确声明 `supports_vision`，并从 Billing 的 `ModelMap.supports_vision` 透传。
  - `crates/gateway/src/facade/conversation.rs`：在请求流转环节集成租户分组与模型的视觉能力检测，支持异步接入上游 Vision Fallback 模型进行图片转写与缓存。
  - `crates/gateway/tests/vision_fallback_test.rs`：新增完整的集成测试用例，覆盖能力判定、纯文本模型自动降级、多模态模型原样保留、图片缓存命中与 Mock 视觉服务调用。

## 审计 A（规格盲审）
- 独立写下的验收标准：
  1. Spec §14.3 要求：不支持看图的模型自动先用视觉模型转文字（参考 AnyBridge）。
  2. 纯文本模型（如 DeepSeek-V3, DeepSeek-R1, Qwen-Turbo 等）收到含图片的对话请求时，网关不得将 raw image 抛给上游引发 400 Bad Request，而必须自动触发视觉降级，将其安全转换为上下文友好的文字描述。
  3. 支持视觉的多模态模型（Claude 3+, GPT-4o, Gemini 等）继续保留多模态看图流程。
  4. 支持配置外部 Vision Fallback 模型及缓存，避免重复看图产生多余开销。
- 对照结果：
  1. 标准 1：PASS (`transcribe_image_with_provider` 与 `format_fallback_description` 完整落地)
  2. 标准 2：PASS (测试 `test_vision_fallback_on_text_only_model` 验证触发降级文本替换)
  3. 标准 3：PASS (测试 `test_multimodal_model_preserves_attached_image` 验证原生保留)
  4. 标准 4：PASS (测试 `test_fallback_transcription_cache` 与 `test_upstream_vision_transcription_mock` 均通过)
