# P4-6 审计报告: 一键导入供应商（CC Switch / Cherry Studio）

## 1. 任务概述
- **任务目标**: 支持从主流 LLM 客户端与切换器（CC Switch、Cherry Studio 等）一键导入供应商与模型配置：
  1. 支持 Cherry Studio 导出的 JSON 结构（包括完整设置导出、多模型数组对象解析）
  2. 支持 CC Switch 供应商配置结构（列表模式、字典映射模式、多种字段别名兼容）
  3. 支持格式自动检测 (`SourceFormat::Auto`)
  4. 支持模型推理与视觉能力自动标记 (`to_model_infos`)
  5. 提供 HTTP API 门面 (`POST /api/v1/admin/providers/import`)，并支持自动挂载同步至虚拟化模型库 (`VirtualizationStore`)
- **极简原则 (Ponytail)**:
  - 复用已有的 `serde_json`，无需引入额外的外部 YAML 或专用配置迁移 crate
  - 扁平化归一化函数，单个解析器兼容多种字段别名 (`url`, `baseUrl`, `base_url`, `key`, `apiKey`, `api_key`)
  - 零样板，一条管道直通 `Provider` / `ProviderKey` / `ModelInfo`

## 2. 变更范围
- `crates/gateway/src/provider/import.rs`: 导入解析核心模块（`SourceFormat`, `ImportedProvider`, `import_providers` 等）
- `crates/gateway/src/provider/mod.rs`: 导出 `import` 模块及类型
- `crates/gateway/src/facade/provider_import.rs`: Axum 路由处理器 (`ProviderImportHandler`)
- `crates/gateway/src/facade/virtualization.rs`: 扩展 `upsert_model` 便于动态导入模型实时可见
- `crates/gateway/src/facade/mod.rs`: 注册 `provider_import` 门面
- `crates/gateway/tests/provider_import_test.rs`: 5 个测试用例，覆盖 Cherry Studio、CC Switch 两种结构、自动探测、HTTP 门面及异常防御

## 3. 测试验证
- `cargo test --test provider_import_test`: 全部通过 (6/6 passed)
- 覆盖率验证：
  - `test_cherry_studio_export_import`: 验证 Cherry Studio 标准导出反序列化与能力推断
  - `test_cc_switch_config_import`: 验证 CC Switch 列表与别名字段、去除尾部斜杠
  - `test_cc_switch_dict_format`: 验证 CC Switch 对象字典格式
  - `test_auto_detection`: 验证 `Auto` 模式特征自识别
  - `test_provider_import_facade_and_virtualization_sync`: 验证 HTTP 导入与 VirtualizationStore 实时同步
  - `test_invalid_import_payload_rejection`: 验证非法 JSON 与空配置的友好报错
