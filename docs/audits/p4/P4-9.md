# P4-9 审计报告: Web 自助激活门户（余额/到期/换绑）

## 1. 任务概述
- **任务目标**: 为终端用户与分发渠道提供零依赖的 Web 自助服务门户及配套 API：
  1. 卡密状态、实时可用算力与总面额、所属套餐及到期时间查询 (`POST /api/v1/portal/query`)
  2. 未激活卡密一键自助激活与首登设备绑定 (`POST /api/v1/portal/activate`)
  3. 自助设备解绑与换绑 (`POST /api/v1/portal/unbind`)，即时增加 token_version 吊销旧设备会话
  4. 叠加充值券/续费码核销充值 (`POST /api/v1/portal/topup`)，余额增加并记录流水
  5. 内置自包含单页 Web 应用 (`GET /portal`)，纯 HTML/CSS/JS，无第三方 CDN 依赖，适配手机与桌面端
  6. 路由与认证整合：公开路由白名单免 JWT 访问，用户无需客户端登录即可自助处理
- **极简原则 (Ponytail)**:
  - 复用已有的 `BillingEngine`（`find_card_by_code`, `activate`, `unbind_device`, `redeem_topup`）
  - 前端以常量 HTML 字符串内联嵌入 Gateway 二进制中，零打包体积膨胀、零文件依赖
  - 纯标准 Fetch API 与原生 CSS，开箱即用

## 2. 变更范围
- `crates/gateway/src/facade/portal.rs`: 核心实现，包含 4 个 JSON API 处理器与 1 个 SPA 网页处理器
- `crates/gateway/src/facade/mod.rs`: 导出 `pub mod portal;`，提供 `register_portal_facades`，并在 `into_router_with_auth` 中将 `/portal` 及 `/api/v1/portal/*` 加入公开白名单
- `crates/gateway/tests/portal_test.rs`: 包含 4 个端到端集成测试，覆盖查询、激活、解绑、充值及网页呈现

## 3. 测试验证
