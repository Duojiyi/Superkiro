# Superkiro 前端体验与接口对齐复核

日期：2026-09-20

## 范围与方法

桌面客户端、管理员工作台、官网、换绑页、文档站。客户端与管理端分别由独立实现代理审查修复，另一个只读代理先独立列出问题，再复核修正。属于独立交叉审查，不声称满足严格实验双盲。

## 已修复

- 桌面：480×540 紧凑布局与 620×820 标准布局，减少空白，设置分组、操作排列、诊断布局、文案与键盘焦点；保留金属设计和真实波形动效。
- 桌面：无会话仅开放诊断、报告、还原及登录；自动公告受会话限制；清除系统保存卡密失败时保留错误并支持重试。
- 桌面：继续保留确认后自动关闭 Kiro 的还原流程，以及还原后保留当前卡密授权和余额的既有修复。
- 管理端：独立登录页、匿名不挂载后台工作区；九个页面的窄屏布局；危险操作确认、防重复提交、复制失败恢复、弹窗背景隔离与焦点恢复。
- 管理端：公告输入校验；发布结果不明确时禁止盲重试，必须重新读取公告列表并人工确认后解除限制。
- 门户：单文件下载和还原文档与客户端行为对齐；未激活卡密显示首次启用后计时；请求处理中按钮反馈；离页中止请求并拒绝迟到响应回写。
- 配套云端：公开只读公告接口；管理会话真实有效期与可选 TOTP 契约；财务明确估算而非真实营收；调账幂等原因与操作人校验；供应商导入保留分组归属。
