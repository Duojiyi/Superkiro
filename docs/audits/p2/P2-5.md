## 审计 B：对抗性盲审 (Adversarial Blind Audit)

在 `crates/billing/tests/pricing_test.rs` 中编写 10 组独立严苛测试用例：

### 对抗场景 1：成本加成模式与分级缓存 Token 扣费对抗
- **测试**：`test_pricing_mode_cost_plus_with_tiered_cache_tokens`
- **验证**：输入 1,000 tokens ($3.00/1M)、输出 500 tokens ($15.00/1M)、缓存创建 2,000 tokens ($3.75/1M)、缓存读取 10,000 tokens ($0.30/1M)，美元成本精确为 $0.0210，按 7.20 汇率折合 0.1512 CNY (151,200 微元)，在 1.25 毛利倍率与 0.01 面值下精确扣收 18,900,000 微积分 (18.9 积分)。
- **实测结果**：`provider_cost_micro_cny` 与 `credits_charged` 100% 精确匹配，预留额度超支时受严格拒绝保护。**PASS**。

### 对抗场景 2：固定单价模式与成本解耦对抗
- **测试**：`test_pricing_mode_fixed_decoupled_from_cost_with_cost_ledger`
- **验证**：用户按固定 10 积分/1M 输入、30 积分/1M 输出、2.5 积分/1M 缓存读取结算（实收 75,000 微积分），同时后台成本账本独立按底价记录上游供应商真实成本 115,200 微元。
- **实测结果**：扣费与上游成本完全解耦，但毛利报表数据源完整记录成本。**PASS**。

### 对抗场景 3：按次包干模式与预留即 N 对抗
- **测试**：`test_pricing_mode_per_call_flat_fee_and_reservation`
- **验证**：单次请求预留额度精确冻结包干费 500,000 微积分；结算时即便产出大量 token 亦固定收取 500,000 微积分，成本侧如实记录 100,100 微元。
- **实测结果**：预留即包干金额，结算零偏差。**PASS**。

### 对抗场景 4：RateCard 版本时间旅行与历史不可篡改对抗
- **测试**：`test_rate_card_versioning_and_historical_immutability`
- **验证**：
  1. t=100 发布 v1 (底价 $3/$15)；
  2. t=200 发布 v2 (底价涨为 $4/$20)；
  3. t=500 预设未来版本 v3 (底价 $5/$25)；
  4. 验证 t=150 请求解析到 v1，t=250 与 t=300 解析到 v2（v3 未生效）；
  5. 验证 t=150 已结算的历史账本条目永久固定为 v1，不受后续调价影响。
- **实测结果**：版本解析与历史追溯 100% 幂等一致。**PASS**。

### 对抗场景 5：三级叠乘倍率一致性
- **测试**：`test_stacked_multipliers_model_map_group_and_rate_card`
- **验证**：RateCard 毛利倍率 (1.5) × 分组倍率 (1.2) × 模型映射倍率 (2.0) = 3.6 倍，实收金额精确为底价成本的 3.6 倍。
- **实测结果**：三级叠乘计算严丝合缝。**PASS**。

### 对抗场景 6：毛利汇总报表与人工调账审计隔离
- **测试**：`test_gross_margin_report_and_manual_adjustment`
- **验证**：毛利统计函数 `get_margin_summary()` 从账本聚合收入与成本，并正确排除人工补偿退费（`Adjustment`）对供应商真实成本的污染。
- **实测结果**：毛利统计严密可靠。**PASS**。

### 对抗场景 7：零用量与空 Token 容错
- **测试**：`test_audit_b_zero_and_empty_tokens_tolerance`
- **验证**：客户端异常发起 0 token 请求，网关不出现除零异常或空指针崩溃，成本与扣费安全记录为 0。
- **实测结果**：健壮通过。**PASS**。

### 对抗场景 8：亚分级（Sub-cent）极小金额精度对抗
- **测试**：`test_audit_b_fractional_sub_cent_rounding_precision`
- **验证**：DeepSeek $0.14/1M 极低成本模型，即使单次仅消耗 10 token，通过整数微单位运算杜绝浮点下溢为负或零值漂移。
- **实测结果**：运算安全无误。**PASS**。

### 对抗场景 9：通配模型（`*`）回退策略
- **测试**：`test_audit_b_wildcard_model_fallback`
- **验证**：未特别指定定价策略的生僻模型自动降级至当前 RateCard 的通配规则 `*`。
- **实测结果**：自动回退生效。**PASS**。

### 对抗场景 10：跨分组 RateCard 强隔离
- **测试**：`test_audit_b_cross_group_rate_card_isolation`
- **验证**：Standard 分组（50 积分包干）与 Enterprise 分组（10 积分包干）使用不同 RateCard 互不串扰。
- **实测结果**：租户隔离严密。**PASS**。
