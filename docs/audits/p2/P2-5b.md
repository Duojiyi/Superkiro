## 审计 B：对抗性盲审 (Adversarial Blind Audit)

在 `crates/billing/tests/workbench_test.rs` 与 `crates/gateway/tests/virtualization_test.rs` 中编写系统级对抗测试用例：

### 对抗场景 1：主流大模型底价预设覆盖性与安全回退
- **测试**：`test_builtin_model_presets`
- **验证**：Claude 3.5 Sonnet ($3.00/1M 输入, $15.00/1M 输出, 1.30 倍率)、DeepSeek V3 ($0.14/1M 输入, $0.28/1M 输出, 0.014 缓存命中) 等预设参数 100% 精确；未定义模型安全返回 `None` 杜绝注入空指针。
- **实测结果**：**PASS**。

### 对抗场景 2：所见即所得定价表双向联动与精度推导
- **测试**：`test_wysiwyg_pricing_sheet_bidirectional_linking`
- **验证**：
  1. 正向倍率推导（1.25x 倍率下毛利率精确为 20.0%，输入折合 2700 积分/1M）；
  2. 目标毛利反推（目标 30% 毛利率反推倍率为 1.42857x，反向复算毛利率完全闭环）；
  3. 固定积分售价反推（目标 3,000 积分/1M 反推毛利率与倍率）。
- **实测结果**：三向闭环计算无数值漂移。**PASS**。

### 对抗场景 3：定价模拟器历史用量沙箱演练（防调价事故）
- **测试**：`test_pricing_simulator_over_historical_usage`
- **验证**：抽取 3 条真实历史用量记录，套用候选提价版本（底价提高 33%，倍率从 1.2 提至 1.5）。模拟器准确测算出：模拟总积分提高、总收入增长、毛利率由 16.6% 跃升至 33.3%、用户燃烧率提高（burn rate ratio > 1.0），30 天月卡预期寿命由 30 天缩短至 24 天以下。
- **实测结果**：模拟指标详尽准确，为生产改价提供完备护栏。**PASS**。

### 对抗场景 4：月卡套餐逆向精算校准
- **测试**：`test_plan_calibrator`
- **验证**：输入 50,000 积分月卡、30 天目标、每日 100k 输入/20k 输出，系统自动算出每日燃烧基准 1,666.67 积分，推荐成本加成倍率 3.858x，预计供应商成本 129.6 元，预期毛利率 74.08%。
- **实测结果**：精算模型符合商业逻辑与运营诉求。**PASS**。

### 对抗场景 5：版本发布不可篡改审计追踪
- **测试**：`test_one_click_publish_rate_card_version_with_audit_log`
- **验证**：发布 v1 生成首版审计日志（previous_version_id = None）；随后发布 v2 生成关联审计日志（previous_version_id = Some("rcv-pub-v1")），操作人与变更原因全程保全，不可逆转。
- **实测结果**：审计链条完整严密。**PASS**。

### 对抗场景 6：Kiro 原生 UI `/getUsageLimits` 积分口径与实时余额映射
- **测试**：`test_audit_b_get_usage_limits_reflects_live_card_credits_and_plan`
- **验证**：卡密绑定 50 积分额度、已消耗 12.5 积分，分组套餐名为 `KIRO ENTERPRISE PRO`。发起的 `/getUsageLimits` 响应体直接返回 `usageLimit: 50.0`, `currentUsage: 12.5`, `subscriptionTitle: "KIRO ENTERPRISE PRO"`, `displayName: "Credit"`。
- **实测结果**：Kiro 客户端展示口径完全对接，消除请求数与积分口径的分歧。**PASS**。
