## 审计 B：对抗性盲审 (Adversarial Blind Audit)

在 `crates/billing/tests/provider_test.rs` 与 `crates/gateway/tests/provider_governance_test.rs` 中实施端到端对抗演练：

### 对抗场景 1：平滑加权轮询 (SWRR) 流量交替数学验证
- **测试**：`test_swrr_weighted_distribution`
- **验证**：Key A 权重 3，Key B 权重 1。连续进行 8 次轮询。
- **实测**：
  1. 产出严格序列：`[Key A, Key A, Key B, Key A, Key A, Key A, Key B, Key A]`；
  2. 流量比例严格为 6:2 = 3:1；
  3. 请求均匀穿插分布，无尾部堆叠或集中轰炸单 Key 的现象。
- **实测结果**：**PASS**。

### 对抗场景 2：单 Key 冷却熔断与到期自动复活
- **测试**：`test_cooldown_skips_key_and_recovers_after_expiry`
- **验证**：Key A 与 Key B 初始均健康。Key A 在 t=1000 发生故障被冷却 60 秒（冷却至 t=1060）。
- **实测**：
  1. 在 t=1030 连续进行 5 次获取，Key A 被 100% 绕过，所有流量均安全导向 Key B；
  2. 在 t=1060 冷却时间截点到达后，Key A 自动重新变为可用，SWRR 恢复两 Key 交替轮询。
- **实测结果**：**PASS**。

### 对抗场景 3：全部 Key 冷却耗尽阻断与 Kiro 重试报文
- **测试**：`test_all_keys_in_cooldown_error`
- **验证**：池中所有 Key 均因并发打满进入冷却，分别剩余 20s 与 50s。
- **实测**：
  1. `select_key` 准确返回 `GovernanceError::AllKeysInCooldown`；
  2. `next_recovery_secs` 准确返回 20 秒；
  3. 对接网关后直接映射为 HTTP 429 `ThrottlingException` + `Retry-After: 20`。
- **实测结果**：**PASS**。

### 对抗场景 4：上游 429 速率超限触发秒级透明故障转移
- **测试**：`test_transparent_failover_on_429`
- **验证**：上游针对高权重 Key A 返回 HTTP 429 Too Many Requests；低权重 Key B 正常提供流式响应。
- **实测**：
  1. 网关捕获 Key A 429 异常，立刻将其标记为冷却（`health_state = Degraded`）；
  2. 自动无缝切换到 Key B，成功获取 SSE 响应流；
  3. 下游顺利接收到完整流式内容，会话未中断。
- **实测结果**：**PASS**。

### 对抗场景 5：上游 401 凭证失效永久禁用与故障转移
- **测试**：`test_failover_on_401_marks_key_unhealthy`
- **验证**：Key A 传入失效或已被吊销的密钥，上游返回 HTTP 401 Unauthorized。
- **实测**：
  1. 网关识别 401 错误，判定 Key 永久失效，立即标记 `health_state = Unhealthy` 且 `enabled = false`；
  2. 故障转移至健康 Key B，顺利完成请求；
  3. 后续轮询彻底移出 Key A，避免无谓重试死 Key。
- **实测结果**：**PASS**。

### 对抗场景 6：客户端 400 格式错误非重试保护
- **测试**：`test_non_retryable_400_does_not_failover`
- **验证**：上游返回 400 Bad Request（如请求参数不合法）。
- **实测**：
  1. 准确识别为非重试错误，立刻返回 `GovernanceError::NonRetryable`；
  2. 未触发多余 Key 故障转移，未导致任何 Key 被误判冷却。
- **实测结果**：**PASS**。

### 对抗场景 7：连通性探针与 TTFT / 吞吐量基准评测
- **测试**：`test_connectivity_probe_and_benchmark`
- **验证**：对 Mock 上游发起 `probe_provider_key`。
- **实测**：
