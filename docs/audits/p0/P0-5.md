## 审计 B（对抗盲审）
- 最小必填集与破坏性反例测试：
  - 反例 1：`ListAvailableProfiles` 若返回 `[]`，Kiro 内部的 `ProfileArnGuard` 抛出 `No profiles available from ListAvailableProfiles` 并拦截后续交互。因此返回体必须至少包含一个有效 ARN。
  - 反例 2：`getUsageLimits` 中若 `usageLimit` 缺失或为 0，前端在计算 `currentUsage / usageLimit` 时会触发 `NaN` 导致 UI 进度条渲染错误。因此最小集必须显式指定大于 0 的 `usageLimit`。
  - 反例 3：`ListAvailableModels` 中若 `modelId` 缺失，下拉框将无法定位选定项。
- 结论：PASS
