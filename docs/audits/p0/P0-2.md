## 审计 B（对抗盲审）
- 重点核验（防假阳性）：
  - 审查：如果仅在启动时注入 `AWS_ENDPOINT_URL=https://localhost:8443`，Kiro 会打向哪里？
  - 证据代码核对：`extension.js` 中 `jRi` 构造 `Mme` 客户端时显式传入了 `endpoint: "https://runtime.us-east-1.kiro.dev"`。AWS SDK v3 的 `LEl` 判定 `isCustomEndpoint = true`，导致 `AWS_ENDPOINT_URL` 被完全忽略。若非本次静态深入逆向，仅观察“Kiro 正常响应”极易误判为已成功劫持，实则是打向了官方后端的假阳性。
  - 对抗构造：尝试在 VS Code 配置层注入 `codewhisperer.config.krsEndpoints` 与 `cpsEndpoints`，证实其在 `IVr` 中存在原生读取钩子，结合扩展热补丁可 100% 封闭假阳性漏洞。
- 结论：PASS
