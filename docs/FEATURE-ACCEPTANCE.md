## 可重复执行

从项目根目录执行（交互输入 SSH 密码，不在命令行填写）：

~~~powershell
python test_real_kiro_acceptance.py probe
python test_real_kiro_acceptance.py prepare
# 完成 IDE 操作并关闭测试窗口后：
python test_real_kiro_acceptance.py cleanup
~~~

probe 仅探测并在结束时禁用临时卡；prepare 建立独立 profile、独立 HOME 下的临时认证令牌并启动已安装的 Kiro，不修改安装文件和原账户。不要把 .acceptance 目录提交或分享。cleanup 禁用测试卡并删除临时令牌。私有 CA 仅通过子进程 NODE_EXTRA_CA_CERTS 传入，不全局关闭 TLS 校验。

探测输出 deployment-readiness-results.json 中的状态是观测结果，不是功能放行证书。后续上线须逐条满足上表，未实现项不能标为通过。
