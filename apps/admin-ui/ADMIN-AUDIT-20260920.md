# 管理后台审计与迭代（2026-09-20）

## 范围与结论

依据用户提供的八张截图，检查登录页及九个工作区页面的源码、接口调用、状态反馈和浏览器交互。本轮修复在本地完成，未访问生产后台或修改生产数据。浏览器使用隔离 fixture 数据，不等同于生产验收，也不代表后端已完成独立安全审计。

## 已修复

| 页面 | 发现与处理 |
| --- | --- |
| 全局 | 普通按钮近似文字、禁用状态过淡、表单边界不清。统一有边框的次级按钮、实心主按钮、危险按钮、禁用状态及键盘焦点；缩减宽屏侧栏、标题空白，保留移动端表格滚动。 |
| 卡密 | “导出 CSV”实际只导出本次生成结果，现更名；所选卡密导出与批量封禁分级显示；压缩冗长操作说明，保留明文泄漏提示和选择范围。历史卡密没有明文时明确提示查阅发放记录，不伪装成可恢复。 |
| 卡密功能 | 单卡状态变更期间禁用状态按钮；接口返回 success:false 时显示错误。批量制卡负确认不再无提示结束。原有批量逐项结果、导出确认、失败选择保留和会话过期保护保持不变。 |
| 调用追踪 | 搜索从长表底部移至顶部；增加每页 20 条分页、匹配数量、空结果提示；搜索支持中文状态，结果显示中文徽标。搜索改变时回到第一页。 |
| 供应商 | API 密钥健康状态中文显示，冷却状态不再显示为绿色健康；“在下方添加”从无效禁用按钮改为可跳转操作；修正密钥字段标题。 |
| 供应商功能 | 手动修改供应商/Key ID 后清空旧发现结果；切换 Key 重建编辑器，防止旧请求结果填入新 Key；保存和导入均检查 success，负确认不清空密钥或提示成功。 |
| 分组与模型 | 文案改为配置、发布、生效时间等管理口径；技术参数保留在高级配置。读取和发布均检查成功标志，负确认不清除编辑内容与变更原因。 |
| 运营概览 | 改为运营指标描述；保留“最近样本”“非全天”及估算边界，避免误认全天成功率或实际利润。 |
| 财务对账 | 检查现有面值/采购估算、精确金额转换及成本覆盖提示；本轮未变更结算算法。缺少采购成本时不伪报利润。共享按钮、输入框和布局样式同步生效。 |
| 公告 | 改为明确的受众、有效期与发布说明。验证空标题、过长标题、发布超时、刷新失败及人工核对后解锁流程。 |
| 安全 | 删除固定“TOTP 未接入”断言，改为真实会话返回的认证状态；密钥数量显示实际读取数量；全部会话下线增加确认，取消不发送撤销请求。发布审计说明明确覆盖范围。 |
| 登录 | 与全局一致的表单、按钮及禁用状态；保留服务端驱动 TOTP、匿名请求门禁和会话过期卸载机制。 |

## 未解决的能力边界

1. 追踪接口当前只加载最近最多 100 条，新增分页是客户端分页，不是全历史查询；全天聚合、时间范围和服务端检索仍需后端接口。
2. 配置发布审计不是全部管理操作审计；外部身份系统、多租户隔离和基础设施密钥轮换不因本次 UI 修改而具备。
3. 已存储的英文供应商/分组名称、操作原因及模型 ID 是业务记录，本轮不自动翻译或覆盖历史数据。
4. 实际收款、采购账单与毛利核对未接入；现有财务数字继续明确标注估算与覆盖范围。
5. 批量制卡在超时后仍依赖管理员核对列表，已增加原标签页跨刷新待核对锁及可搜索的持久批次备注；该保护不能替代服务端幂等键；后续应在发卡接口实现幂等与结果查询，再开放可靠自动重试。
6. 新增分组、首个价格版本等仍依赖高级 JSON 编辑，尚未提供完整向导。API 密钥、商业和财务表单已统一离页确认与刷新保护，但不自动保存秘密草稿。
7. 生产部署、生产大数据量测试与真实管理员操作验收未执行。本轮不改变已知发布审计阻塞。

- 浏览器认证：`npm --prefix apps/admin-ui run test:browser`。
- 九页视觉与交互：`node apps/admin-ui/tests/visual-authenticated.cjs`。
- 新增断言：追踪分页/中文筛选/无匹配，旧模型发现清除，Key 与配置发布负确认，卡密状态负确认，取消全部会话下线不写入。
- 浏览器覆盖 1440px 桌面、390px 移动视觉以及 320px 窄屏溢出；截图为本地测试数据，位于 `visual-check/authenticated/`。
