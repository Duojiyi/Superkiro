使用文档

快速开始模型与积分换机与解绑恢复原始配置连接故障版本与下载

第一次使用 Superkiro

Windows：下载 x64 单文件客户端，打开即可使用。

01 安装并验证卡密

从官网下载客户端。输入卡密并验证，确认等级、积分和有效期后进入主界面。客户端和网页的卡密验证均为只读查询，不激活卡密、不绑定设备，也不会启动未激活卡密的有效期计时。

02 确认 Kiro 安装位置

客户端会自动识别安装路径；未找到时，点击“选择安装位置”手动指定。

03 点击连接，开始使用

保存 Kiro 中未完成的工作，再在客户端手动点击并确认“启用连接”，才会请求服务端激活卡密并按策略绑定当前电脑。未激活卡密的有效期从服务端成功激活时开始计时，不以 IDE 连接完成或发送第一条消息为起点；已激活卡密不会因再次验证或连接而重新计时。连接过程可能重启 IDE；完成后，在 Kiro 中选择模型并发送消息。

模型与积分

可用模型、服务等级、剩余积分和有效期以实际卡密权益及客户端返回为准。官网不展示模拟账户用量。

查看真实用量

换机与解绑

优先在旧客户端恢复原始配置。网页无法修改或恢复旧电脑上的文件。

旧设备仍可使用

保存工作，在旧客户端恢复原始配置，再进入换机管理验证卡密并确认解绑。解绑会使旧访问凭证失效，积分与有效期保持不变。

旧设备无法使用

可在网页验证同一卡密，选择已绑定设备并申请解绑。解绑后，在新客户端输入卡密完成绑定。旧电脑文件需要在设备恢复可用后自行恢复。

换机受卡密的次数与冷却限制，以服务端结果为准。解绑成功仅释放设备绑定；新客户端能否启用仍受卡密状态、余额和有效期限制，请先验证。卡密可用时，在新客户端绑定不会重复消耗本次换机次数。如再次换机时提示限制，请按服务端结果处理，不要连续提交。

恢复原始配置

先保存 Kiro 中的工作，再在原电脑上的 Superkiro 客户端点击“还原 Kiro 配置”。确认后，客户端会请求 Kiro 关闭并还原配置；Kiro 询问是否保存时，请在 Kiro 中处理。Kiro 未关闭时不会被强制结束，只有你在客户端再次确认后才会强制关闭。

还原完成后仍留在客户端主界面，保留本次卡密会话与已获取的积分信息；还原不会退出登录或解除设备绑定。再次使用时，点击“启用连接”。恢复本地文件与解除服务端设备绑定是两件事。只在网页解绑，不会恢复本地配置；请确认客户端的恢复结果。

恢复未完成

保留本地备份与错误提示。确认安装路径和文件权限，再按客户端提示重试；客户端提示需要重新安装 Kiro 时，从官网安装后再次还原。若无法结束 Kiro 进程，请保存工作后手动关闭，再次还原。

连接故障

  1. 确认卡密有效、积分充足，当前电脑与绑定设备一致。
  2. 确认 Kiro 安装路径正确，保存工作并按提示重启 IDE。
  3. 检查网络连接；遇到限流请等待，不要频繁点击重试。
  4. 仍无法连接时，恢复原始配置并记录脱敏后的错误信息，联系支持方。

不要分享完整卡密、访问令牌或包含敏感信息的日志。

版本与下载

在官网下载区选择对应系统的安装包。安装后客户端会自动更新到最新版本。

Windows

macOS
